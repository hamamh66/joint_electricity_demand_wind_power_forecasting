# Joint Electricity Demand and Wind Power Forecasting for Smart Power System Operation

## Overview
This repository contains the implementation of an integrated smart-grid decision-support framework that combines electricity-demand forecasting, wind-power forecasting, residual-load estimation, explainable AI, and operator-oriented energy-management recommendations.

The framework employs coordinated ExtraTreesRegressor models trained on public datasets, together with cross-dataset feature mapping, LIME explanations, SHAP analysis, residual-load assessment, and rule-based Agentic AI support.

## Datasets
- ElecLoadForcasting (Kaggle)
- WindPowerData (Kaggle)

## Main Features
- Electricity demand forecasting
- Wind power forecasting
- Cross-dataset feature mapping
- Residual-load estimation
- Time-ordered validation
- Rolling-origin validation
- Baseline benchmarking
- LIME explainability
- SHAP explainability
- Agentic AI decision support
- LLM-based operator reporting

## Methodology
1. Data preparation and preprocessing
2. ExtraTrees model training
3. Cross-dataset feature mapping
